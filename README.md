# 地球 Online：单机版

一个把现实生活游戏化的单机网页游戏原型。玩家可以创建现实任务、获得经验和金币、抽取娱乐奖励、使用奖励仓库、记录人际关系与互动，并通过冒险日志和成就系统持续游玩。

## 启动方式

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可游玩。

## 主要功能

- 首页玩家面板：等级、经验、金币、抽卡券、签到、今日概览与属性条。
- 任务系统：每日、每周、主线、支线任务，支持新增、编辑、删除、完成、撤销、筛选和排序。
- 成长结算：完成任务获得金币、经验、抽卡券和属性奖励，经验满足条件后自动升级。
- 娱乐抽卡：单抽、十连、概率展示、十连保底 R、可开关 SR/SSR 保底。
- 奖励仓库：查看、使用和删除抽到的现实娱乐奖励。
- 关系系统：新增人物、记录主观好感/熟悉/稳定度，添加互动记录。
- 冒险日志：自动记录任务、抽卡、奖励、关系、签到、升级等事件。
- 成就与统计：基础成就解锁、累计任务/抽卡/奖励/互动等统计。
- 设置：修改玩家资料、开关动画/保底/系统提示、导入导出存档、重置游戏。

## 存档说明

所有数据保存在浏览器本地 `localStorage` 中，键名为 `earth-online-solo-save`。不需要登录、后端或付费 API。

设置页可以导出 JSON 存档，也可以导入此前导出的 JSON 文件。重置数据前会弹出二次确认。
