# Earth Online

一个把现实行动转化为 PJSK 风格收集动力的本地单机网页应用。

核心循环是：**完成现实任务 → 获得水晶与养成材料 → 招募成员 → 图鉴收集与卡牌养成 → 继续推进现实任务**。

## 当前功能

- 每日、每周、主线和支线任务，支持筛选、排序、编辑、撤销与目标次数逐步推进。
- 今日 Live：完成 1 / 3 / 5 个每日任务时自动领取阶段奖励。
- 任务奖励包含水晶、经验、练习乐谱、奇迹结晶和属性成长。
- PJSK 风格单抽、十连、招募演出、中文成员台词、招募贴纸与兑换所。
- 459 张成员卡牌的角色图鉴与已拥有卡牌一览。
- 卡牌等级、特训、花后解锁、大师等级、收藏标记与筛选。
- 重复成员转化为心愿碎片，用于提升大师等级。
- 首页应援角色，可观察神代类等角色的个人图鉴收集进度。
- 关系记录、冒险日志、成就、签到和本地存档导入导出。

## 本地启动

```bash
npm install
npm run dev
```

按照终端显示的地址在浏览器中打开即可。

生产构建：

```bash
npm run build
```

## 存档

所有进度保存在当前浏览器的 `localStorage` 中，键名为 `earth-online-solo-save`。应用不需要账户、后端或付费 API。

设置页支持：

- 导出、导入 JSON 存档；
- 补充测试水晶与养成材料；
- 重置当前浏览器存档。

从旧版本进入时会自动迁移存档并保留已有任务、卡牌、抽卡记录及关系数据。

## 数据与使用范围

卡牌元数据与中文文本由生成脚本从公开的 Sekai World master data 整理。卡面等相关素材的权利归原权利方所有；本项目现阶段仅作为个人学习和私人使用实验，不用于商业用途。
